Problem Statement

Finding the shortest delivery route between two locations is an important real-world problem. Delivery companies need to select suitable routes to reduce travel distance, time and transportation costs.

This project compares Brute Force, Greedy, Dynamic Programming and Divide and Conquer using the same road network.

Algorithm Comparison

Algorithm Approach Optimal Result Time Complexity
Brute Force Checks all possible simple routes Yes Exponential
Greedy Selects the smallest available edge Not guaranteed O(V²)
Dynamic Programming Stores and reuses subproblem results Yes O(V² × 2^V)
Divide and Conquer Divides route choices into smaller groups Yes Exponential
